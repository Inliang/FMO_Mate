设备坐标

FMO 日志备份

从设备下载完整 QSO 日志（/api/qso/backup）。设备导出需要几秒时间， 页面会先发起导出、稍后自动在新标签页下载（.db 或 .zip）。

--
准备就绪

若下载到的文件为空或报错，说明设备还没导出完，等 10 秒再点一次「直接下载」。 另：本页以 https 打开时（如 GitHub Pages），浏览器会拦截对设备 http 地址的 iframe 请求，此时将自动跳过「发起导出」步骤，只做下载。
